# Pembuka RasaNusantara dengan animasi mengetik

## 20 Oktober 2026 — Pembuka mengetik dan mangkuk bergerak (v22)
Revisi sesuai persetujuan pengguna menggantikan kebijakan v21 tanpa waktu minimum. Pada pembukaan pertama tab, mangkuk SVG naik 12px dan muncul selama 500ms setelah jeda 200ms; tiga uap naik bergantian dan berubah opacity. Kalimat Menyiapkan cerita dan rasa… diketik per karakter sekitar 40ms, dengan kursor tipis yang berhenti saat selesai. Pengetikan tidak diulang saat koneksi lambat. Placeholder tak terlihat menyediakan ukuran kalimat penuh agar layout tidak bergeser. Teks pembaca layar selalu kalimat lengkap; teks visual bertahap dan placeholder aria-hidden. Tidak membuat video atau menambah dependency.
Kesiapan aset tetap terpisah dari intro. Katalog memiliki timeout 12 detik dan aset/font maksimum 4 detik setelah katalog, seperti sebelumnya. Pembukaan pertama dapat selesai setelah aset siap dan setidaknya 1,55 detik berlalu sejak komponen terpasang, lalu bergeser naik 24px dan memudar 250ms; total sekitar 1,8 detik untuk koneksi cepat. Shell masih inert dan scroll body dikunci hingga selesai. Penanda rn:intro:v1:seen=1 baru ditulis setelah masuk berhasil. Refresh dalam sesi tab yang sama langsung memakai teks lengkap dan tidak memiliki minimum/exit delay tambahan. Katalog memori tetap mencegah fetch atau intro ulang saat navigasi internal. Jika sessionStorage ditolak, penanda berada dalam memori dokumen; refresh dengan storage ditolak dapat mengulang intro. Error langsung menggantikan animasi dengan pesan dan retry, tidak menandai intro berhasil. Timer dan listener dibersihkan saat unmount/perubahan kondisi. Reduced motion, termasuk diaktifkan saat mengetik, langsung memakai teks lengkap dan tidak menambah minimum/exit delay. Animasi dekoratif dipause ketika dokumen tersembunyi. API, data resep, OG dan rahasia server tidak berubah.
Validasi: TypeScript dan build produksi lulus, 30 tes domain/provider/origin lulus, dan 95 skenario browser terverifikasi. Run suite lengkap menghasilkan 94 lulus dan satu kegagalan fixture: tes wheel lama berjalan sebelum intro ditutup, saat body memang terkunci. Fixture ditambah penantian startup tertutup; setelah koreksi, seluruh delapan tes usability dijalankan ulang dan lulus. Tidak ada perubahan runtime aplikasi untuk mengakali tes, dan tidak mengklaim run awal 95/95. Sembilan tes startup meliputi kesiapan/kunci shell, error/retry, timeout, reduced motion, urutan karakter dan ukuran ruang tulisan, kesiapan cepat/lambat, fase keluar/penanda sukses, refresh tanpa replay, perubahan reduced motion saat entry dan penyimpanan sesi ditolak. Regresi lain mempertahankan alur bahan, rekomendasi, resep, Cooking Mode, riwayat AI, navigasi kanan, media dan metadata berbagi. Pengujian provider memakai simulasi, tidak menambah panggilan Gemini nyata untuk revisi UI ini.
Visual diperiksa bersama pada desktop Chrome 1440×900, Chrome sentuh 412×915, serta WebKit emulasi iPhone 390×844 dan 844×390: tiga fase pengetikan (200/600/1280ms) dan aplikasi siap, total 16 screenshot, tanpa pageerror. Timeline CSS sengaja diseek untuk screenshot deterministik; gambar ini bukan rekaman durasi jaringan nyata. Pengujian bukan iPhone/Android fisik atau pemeriksaan pembaca layar fisik. Tidak mengklaim semua perangkat bebas lag. Tidak ada perubahan estetika tambahan setelah review. Launcher port 3001 memuat build terbaru.
